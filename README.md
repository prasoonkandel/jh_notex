# JingHua Notex

> JingHua Notex is a simple, web-based notes app that lets you create an account without sharing personal information like your email address or phone number. You can create, edit, and store your notes online and access them whenever you need them.

## Features
- Secure RESTful backend built with FastAPI
- MySQL database for storing and managing notes
- JWT-based authentication and secure password hashing
- Complete note management (Create, Read, Update, Delete)
- Automatic API documentation using FastAPI Swagger UI
